## 2024-06-25 - CryptoJS HMAC Hot Path Optimization
**Learning:** In highly repetitive hot loops like Monte Carlo simulation seed engineering (e.g., `generateFloat` in `fairnessEngine.ts` and `aimingWorker.ts`), creating new `CryptoJS.HmacSHA256` instances and converting to Hex strings is a major bottleneck. Re-using a cached HMAC instance (`CryptoJS.algo.HMAC.create`, `reset()`, `update()`) and performing bitwise extraction directly from the `words` array (`hash.words[0] >>> 0`) rather than parsing a Hex string significantly improves performance (observed >3x speedup).
**Action:** When using `crypto-js` in synchronous hot paths, avoid full string conversions and object instantiations. Cache the algorithm instance, reuse it, and access the 32-bit `words` array directly using bitwise operators for primitive extractions.
