## 2024-03-30 - Direct Word Array Access for CryptoJS Performance
**Learning:** Extracting deterministic floats or crash multipliers from `crypto-js` HMAC instances using expensive `.toString(CryptoJS.enc.Hex)` conversion stringifies then parses the bits, which is highly inefficient for tight loops. For example, converting the hex string back to a 52-bit crash multiplier, or converting `parseInt(slice, 16)` to a float.
**Action:** Always prefer caching the HMAC instance via `getHmac().reset().update()` and grabbing values directly from `hash.words`. A float in [0,1) can be extracted via `(hash.words[0] >>> 0) / 4294967296`. A 52-bit crash integer can be directly extracted via `(hash.words[0] >>> 0) * 1048576 + (hash.words[1] >>> 12)`. This optimization sped up operations inside worker threads up to 3x.
