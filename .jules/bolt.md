## 2023-10-27 - Bitwise HMAC Optimization
**Learning:** In hot-loop algorithms using `crypto-js` (like HMAC-SHA256 float extraction and Crash calculations), parsing hex strings (`parseInt(hash.slice(...), 16)`) creates a massive performance bottleneck due to string allocations. The first two 32-bit elements of the internal `hash.words` array can be used directly for mathematical calculations with zero string conversions.
**Action:** Use bitwise math (`(hash.words[0] >>> 0) / 4294967296`) to generate secure floats, and `(hash.words[0] >>> 0) * 1048576 + (hash.words[1] >>> 12)` to extract 52-bit integers, effectively bypassing all string conversion overhead in CSPRNG scenarios. Always cache and `.reset()` the `CryptoJS.algo.HMAC` object instead of instantiating new `.HmacSHA256()` objects when the hash key (e.g., server seed) remains constant.
